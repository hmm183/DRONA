# Brag Plan: MARK-V ISRO PS26168 Neural-Inertial Navigation

## What is this app?
An offline, mission-critical edge AI inertial navigation system for Android that guarantees continuous vehicle position tracking through extended GPS blackouts using the V9 Adaptive Projection PATP transformer and hybrid state estimation (IMM-UKF, RBPF, Sliding Window FGO).

## The angle
When satellite signals are jammed, spoofed, or blocked in deep urban canyons and tunnels, ordinary navigation dies. MARK-V delivers military-grade dead-reckoning directly on commodity mobile hardware, shattering ISRO PS26168's < 10% outage drift benchmark with an audited 0.11% simulation drift and 1.44%–3.69% real field trials.
